# NeuroStack AI Layer

> **NeuroStack AI Layer** is the enterprise AI microservice powering intelligent learning capabilities for NeuroStack LMS, combining deterministic algorithms with governed LLM workflows, semantic search using ZVEC, and a provider-agnostic architecture for scalable, multi-tenant deployments.

## Description

Enterprise AI service for NeuroStack LMS, providing LLM-powered intelligence, deterministic learning algorithms, semantic search, and multi-tenant AI capabilities via a Python FastAPI microservice.
